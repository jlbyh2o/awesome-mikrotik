# Contributing to Awesome MikroTik

Thank you for your interest in contributing to Awesome MikroTik! This document provides guidelines for contributing.

## How to Contribute

### Reporting Issues

If you find a broken link, outdated information, or have a suggestion for improvement, please [open an issue](https://github.com/jeremy/awesome-mikrotik/issues/new).

### Adding New Resources

1. **Fork the repository**
2. **Create a branch** for your addition (`git checkout -b add-awesome-resource`)
3. **Add your resource** following the guidelines below
4. **Commit your changes** (`git commit -m 'Add awesome resource'`)
5. **Push to the branch** (`git push origin add-awesome-resource`)
6. **Open a Pull Request**

## Guidelines

### What to Add

- Open-source tools and libraries
- Free scripts and utilities
- Community resources (forums, wikis, etc.)
- Educational resources and tutorials
- Well-maintained projects

### What NOT to Add

- Commercial/proprietary software (unless it has a free tier)
- Resources that are no longer maintained
- Duplicate entries
- Self-promotion without clear value to the community

### Formatting

- Use the following format: `[Resource Name](link) - Brief description`
- Keep descriptions concise (one line when possible)
- Add resources in alphabetical order within each section
- Use proper capitalization and punctuation

### Quality Standards

- Ensure links are working and up-to-date
- Verify that resources are actually open-source or free
- Check that projects are actively maintained (recent commits/updates)
- Make sure resources are relevant to MikroTik/RouterOS

### Pull Request Process

1. **One resource per pull request** - This makes it easier to review
2. **Use clear commit messages** - Describe what you're adding
3. **Check your formatting** - Ensure proper markdown syntax
4. **Test your links** - Make sure all links work
5. **Be patient** - Maintainers will review your PR as soon as possible

## Code of Conduct

Please note that this project is released with a [Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Questions?

If you have questions about contributing, please open an issue and we'll be happy to help!

Thank you for contributing to Awesome MikroTik! 🎉

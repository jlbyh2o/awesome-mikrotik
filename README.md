# Awesome MikroTik [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of awesome open-source tools, scripts, and resources for MikroTik routers and RouterOS.

MikroTik provides a range of networking hardware and software solutions. This repository aims to gather valuable resources, tools, and scripts to enhance the MikroTik experience.

## Official Resources

- [MikroTik Documentation](https://help.mikrotik.com/docs/) - Comprehensive RouterOS documentation and wiki.
- [MikroTik Forum](https://forum.mikrotik.com/) - Official community forum.
- [MikroTik Official Website](https://www.mikrotik.com/) - Official MikroTik website.
- [MikroTik Support](https://help.mikrotik.com/) - Support portal and knowledge base.
- [RouterOS Software](https://mikrotik.com/software) - Download RouterOS software.

## Official Tools

- [MikroTik App (Android)](https://play.google.com/store/apps/details?id=com.mikrotik.android.tikapp) - Official mobile app for configuring MikroTik devices on Android.
- [MikroTik App (iOS)](https://apps.apple.com/us/app/mikrotik/id1323064830) - Official mobile app for configuring MikroTik devices on iOS.
- [Netinstall](https://help.mikrotik.com/docs/spaces/ROS/pages/328142/Upgrading%2Band%2Binstallation) - Recovery tool for installing/reinstalling RouterOS via Ethernet.
- [The Dude](https://mikrotik.com/thedude) - MikroTik's official network monitor application.
- [WinBox](https://help.mikrotik.com/docs/display/ROS/Winbox) - MikroTik's official GUI configuration utility for Windows (works on Linux/macOS via Wine).

## Management and Automation

- [Ansible Collection for RouterOS](https://github.com/ansible-collections/community.routeros) - Community maintained Ansible collection for managing MikroTik RouterOS.
- [Ctrlbit](https://ctrlbit.com/) - Cloud-based management platform for MikroTik devices.
- [Oxidized](https://github.com/ytti/oxidized) - Network device configuration backup tool with support for RouterOS.
- [RouterFleet](https://hotspotbeacon.com/en/opensource/) - Open source centralized router backup and management system.
- [TikCTRL](https://tikctrl.com/) - SaaS management platform for MikroTik devices offering automation and monitoring.
- [Unimus](https://unimus.net/) - Network automation and configuration management solution with strong MikroTik support.

## Monitoring

- [Grafana MikroTik Dashboard](https://grafana.com/grafana/dashboards/10950-mikrotik-routeros/) - Comprehensive Grafana dashboard for MikroTik RouterOS using Prometheus/SNMP.
- [MikroTik Router Monitoring System](https://github.com/ak740/Mikrotik-Router-Monitoring-System) - SNMP based monitoring system.
- [mikrotik-exporter](https://github.com/nshttpd/mikrotik-exporter) - Prometheus exporter for MikroTik RouterOS metrics.

## Libraries and APIs

- [go-routeros](https://github.com/go-routeros/routeros) - Go library for accessing MikroTik devices using the RouterOS API.
- [librouteros](https://github.com/luqasz/librouteros) - Python implementation of the MikroTik RouterOS API.
- [RouterOS-API](https://github.com/socialwifi/RouterOS-API) - Python API client for MikroTik RouterOS.
- [routeros-api-nodejs](https://github.com/alhazmy13/routeros-api-nodejs) - Node.js client for MikroTik RouterOS API.

## Scripts

- [MikroTik Domain Filter Script](https://github.com/smkrv/mikrotik-domain-filter-script) - Bash solution for filtering domain lists and creating DNS static entries for RouterOS.
- [MikroTik Events](https://github.com/osamahfarhan/mikrotik-events) - Scripts that function as event handlers in RouterOS. ⚠️ Potentially inactive
- [MikroTik RouterOS Online Tools](https://irfannjt.github.io/script/) - Free online tools and script generators for RouterOS.
- [MikroTik Scripts Database](https://mikrotik-scripts.github.io/) - Comprehensive database of RouterOS scripts.
- [MikroTik-Scripts](https://github.com/nymurbd/MikroTik-scripts) - Collection of scripts for MikroTik RouterOS. ⚠️ Potentially inactive
- [RouterOS Scripts](https://github.com/eworm-de/routeros-scripts) - Collection of scripts for MikroTik RouterOS automation and management.
- [RouterOS Useful Scripts](https://github.com/gbudny93/RouterOS_Useful_Scripts) - Collection of utility scripts for backups, upgrades, and more.
- [Scripts-MikroTik](https://github.com/n3tuk/scripts-mikrotik) - Set of scripts and Taskfile to build and manage RouterOS configuration scripts for multiple routers and switches. ⚠️ Potentially inactive
